# 事件识别与要素抽取 · 接口对接文档（发给队友）

> 本模块是赛题二全链路的**第一步**：把原始新闻识别成结构化事件。
> 下游的「可信评估」「同源聚合」「脉络追踪」模块都依赖本模块的输出。

---

## 1. 模块在系统中的位置

```
多源金融资讯（原始新闻）
        │
        ▼
┌──────────────────────────┐
│  本模块：事件识别与要素抽取 │  ← 本文档
│  输出：event_name         │
│        event_emotion      │
│        subjects           │
│        impact_objects     │
│        industry           │
│        event_time         │
└────────────┬─────────────┘
             │ 结构化 JSON
             ▼
┌──────────────────────────┐   ┌──────────────────────┐
│ 可信评估与影响评分（队友） │ ← │ 同源事件聚合（队友）  │
│ 需要：event_name/emotion  │   │ 需要：subjects/正文   │
└──────────────────────────┘   └──────────────────────┘
```

**一句话**：给我一篇新闻，我返回"发生了什么事件 + 影响谁 + 利好还是利空 + 什么时间"。

## 2. 接口总览

服务启动：`uvicorn main:app --host 0.0.0.0 --port 8000`

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/event/health` | 健康检查 |
| GET | `/api/event/schema` | 标准化事件知识摘要（公司/行业/事件类型数量） |
| POST | `/api/event/extract` | 抽取**单篇**文章 |
| POST | `/api/event/extract_batch` | 批量抽取 |

接口可视化文档：`http://localhost:8000/docs`

## 3. 输入格式

### 单篇抽取 `POST /api/event/extract`

```json
{
  "article": {
    "article_file_id": "NEWS_MULTISOURCE_D-941286941798",
    "article_title": "问界2025年累计交付新车突破42万辆",
    "content": "赛力斯公告显示，问界2025全年累计交付突破42万辆……",
    "article_source": "上海证券报·中国证券网",
    "article_publish_time": "2026-01-02 10:47:42"
  }
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `article_file_id` | string | 否 | 文章唯一ID（无则填空串） |
| `article_title` | string | **是** | 标题 |
| `content` | string | **是** | 正文全文 |
| `article_source` | string | 否 | 来源网站，默认"未知" |
| `article_publish_time` | string | 否 | 格式 `YYYY-MM-DD HH:MM:SS` |

### 批量抽取 `POST /api/event/extract_batch`

```json
{
  "articles": [ { "article_title": "...", "content": "..." }, { ... } ]
}
```

## 4. 输出格式（下游模块直接消费）

```json
{
  "article_file_id": "NEWS_MULTISOURCE_D-941286941798",
  "article_title": "问界2025年累计交付新车突破42万辆",
  "article_source": "上海证券报·中国证券网",
  "source_type": "新闻",
  "publish_time": "2026-01-02 10:47:42",
  "event_name": "产品技术创新",
  "event_emotion": "正面",
  "impact_direction": "正面",
  "subjects": [
    { "secu_abbr": "赛力斯", "trading_code": "601127" }
  ],
  "impact_objects": [
    { "name": "问界品牌", "type": "产品" }
  ],
  "industry": { "induname": "乘用车", "inducode": "280500" },
  "event_time": "2026-01-02",
  "confidence": 0.8,
  "method": "llm",
  "completion": { "notes": [], "subject_completed": false, "time_completed": false },
  "standardized": { "event_name_exact_match": true, "reason": "..." }
}
```

### 字段说明（下游常用）

| 字段 | 含义 | 下游用途 |
|------|------|----------|
| `event_name` | 标准化事件类型（64 种之一） | 影响严重程度评分 |
| `event_emotion` / `impact_direction` | 情感/影响方向：正面/中性/负面 | 影响方向 |
| `source_type` | 来源类型：新闻/公告/研报/政策文件 | 多源理解辅助 |
| `subjects` | 主体：`[{secu_abbr, trading_code}]` | 关联公司、标的 |
| `impact_objects` | 影响对象：`[{name, type}]` | 预警推送 |
| `industry` | 行业 `{induname, inducode}` | 行业事件聚合 |
| `event_time` | 事件时间 `YYYY-MM-DD` | 脉络追踪时间线 |
| `confidence` | 置信度 0~1 | 过滤/排序 |
| `method` | `llm` 或 `rule` | 判断结果可信来源 |

> **离线批量产出**：无标签数据批量抽取的结果存为 `outputs_event/extracted_{source}.jsonl`（每行一个 JSON，字段同上）。下游若直接读文件，请按行解析，而不要当单个 JSON 数组加载。

## 5. 接入示例

### 方式一：HTTP（推荐，跨语言）

**Python（requests）**
```python
import requests

def extract_event(article: dict) -> dict:
    r = requests.post(
        "http://localhost:8000/api/event/extract",
        json={"article": article},
        timeout=30,
    )
    r.raise_for_status()
    return r.json()

article = {
    "article_file_id": "NEWS_MULTISOURCE_D-1",
    "article_title": "某公司发布新产品",
    "content": "……正文……",
    "article_source": "证券时报",
    "article_publish_time": "2026-01-05 09:40:00",
}
result = extract_event(article)
print(result["event_name"], result["event_emotion"], result["subjects"])
```

**curl**
```bash
curl -X POST http://localhost:8000/api/event/extract \
  -H "Content-Type: application/json" \
  -d '{
    "article": {
      "article_title": "某公司发布新产品",
      "content": "某公司公告称发布新一代产品。",
      "article_source": "证券时报"
    }
  }'
```

### 方式二：Python 直接 import（同项目内）

```python
from event_ner.extractor import EventExtractor

extractor = EventExtractor()  # 首次加载事件体系

result = extractor.extract({
    "article_file_id": "1",
    "article_title": "...",
    "content": "...",
    "article_source": "...",
})

# 批量
results = extractor.extract_batch([article1, article2, ...])
```

## 6. 与各队友模块的对接关系

| 下游模块 | 需要本模块输出的字段 | 对接方式 |
|----------|---------------------|----------|
| 可信评估与影响评分 | `event_name`（严重程度）、`event_emotion`（影响方向）、`subjects`/`impact_objects` | 把本模块输出 JSON 拼进对方的 `article` 输入 |
| 同源事件聚合 | `subjects`（标的）、`content`（语义向量） | 用 `article_file_id` + `subjects` 关联 |
| 脉络追踪 | `event_time`（时间线）、`event_name`、`subjects` | 按 `subjects` + `event_name` 聚合成时间线 |

**完整链路伪代码（供队友C参考）**：
```python
# 1. 本模块：事件识别
event = requests.post("http://localhost:8000/api/event/extract", json={"article": raw}).json()

# 2. 队友：可信评估（把 event 结果拼进去）
trust_input = {**raw, "event_name": event["event_name"], "event_emotion": event["event_emotion"],
               "secu_abbr": event["subjects"][0]["secu_abbr"] if event["subjects"] else ""}
trust = requests.post("http://localhost:8000/api/trust/assess", json={"article": trust_input}).json()

# 3. 队友：预警推送
if trust["is_rumor"]:
    drop()
elif trust["impact_level"] == "高":
    alert(event, trust)
```

## 8. 常见问题

**Q1：`subjects` 为空？**
事件体系只覆盖 84 家标的公司，若新闻主体不在这 84 家内则抽不出公司。此时看 `industry` 字段是否命中行业事件。

**Q2：`confidence` 怎么用？**
LLM 抽取通常 0.6~0.9，规则回退固定 0.5。下游可设阈值（如 <0.5 需人工复核）。

**Q3：`event_time` 为空？**
正文没有明确日期时为空。下游脉络追踪可用 `publish_time` 兜底。

**Q4：批量抽取性能？**
LLM 单条约 1~3 秒（DeepSeek）。批量建议用 `extract_batch`（HTTP 一次传多条）或 Python import 后循环，不要逐条 HTTP。
