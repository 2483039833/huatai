```bash
cd event_extract
pip install -r requirements.txt
```

```bash
python -c "import pandas, requests, fastapi, uvicorn; print('依赖 OK')"
```

## 2. 配置 LLM（已完成 DeepSeek）

当前 `config.json` 已配置 DeepSeek：
```json
{
  "llm": {
    "provider": "deepseek",
    "api_key": "sk-你的密钥",
    "base_url": "https://api.deepseek.com/v1",
    "model": "deepseek-chat"
  }
}
```

切换其他厂商只需改 `provider`（qwen / deepseek / glm）和对应 `api_key`、`base_url`。
不配置密钥时自动进入**规则回退模式**（离线可跑，准确率约 67%）。

**验证连接**：
```bash
python -c "from event_ner.llm_client import LLMClient; print(LLMClient().chat([{'role':'user','content':'回复：正常'}], json_mode=False))"
```

## 3. 数据清洗（任务①）

```bash
python clean_data.py
```

- 读取 `../data/news_*.xlsx`（4 份：带标签训练/测试 + 无标签训练/测试）
- 去重、填充空来源、清理正文、统一时间
- 输出 `../cleaned_data/*.xlsx`

> 数据已在父目录（团队共享），脚本会自动探测路径，无需改代码。

## 4. 标注处理（任务①）

```bash
python -m event_ner.run --prepare-annotation
```

把带标签训练集（1498 条）转成两种训练格式：
- `outputs_event/llm_sft.jsonl` — LLM 微调格式（Chat 风格，用于 LoRA 微调）
- `outputs_event/ner_bio.jsonl` — NER 字符级 BIO 格式（用于 NER+RE 路线）

## 5. 事件识别 + 要素抽取（任务②③④）

### 5.1 对带标签测试集（同时自动出评测报告）
```bash
python -m event_ner.run --source tagged_test
```

### 5.2 对无标签数据批量抽取（产结构化 JSON）
```bash
python -m event_ner.run --source unlabeled_test --limit 1000
```

`--source` 可选：`tagged_test` / `tagged_train` / `unlabeled_test` / `unlabeled_train`
`--limit` 可选：只处理前 N 条（不传则全部）

### 5.3 导出标准化事件知识（产出③）
```bash
python -m event_ner.run --export-schema
```
输出 `outputs_event/event_knowledge.json`：84 家公司、17 个行业、64 种事件类型及定义。

## 9. 常见问题

**Q1：LLM 调用失败 / 超时？**
检查 `config.json` 的 `api_key` 是否正确、网络能否访问 `api.deepseek.com`。失败时会自动回退规则模式（不会报错中断），可看日志 `[LLM] 调用失败: ...`。

**Q2：提示"未找到事件体系文件"？**
说明数据目录不在预期位置。确认 `../data/事件类型_标的.json` 存在；若数据在别处，改 `event_ner/paths.py` 里的候选路径。

**Q3：想换 Qwen 或 GLM？**
改 `config.json` 的 `provider` 和 `base_url`：
- Qwen：`provider=qwen`，`base_url=https://dashscope.aliyuncs.com/compatible-mode/v1`，`model=qwen-plus`
- GLM：`provider=glm`，`base_url=https://open.bigmodel.cn/api/paas/v4`，`model=glm-4-flash`

**Q4：要做 LoRA 微调？**
`outputs_event/llm_sft.jsonl` 已是标准 Chat 格式，可用 `transformers + peft` 直接加载微调（依赖见 requirements.txt 注释部分）。

**Q5：API 密钥安全？**
`config.json` 已加入 `.gitignore`，**不要提交到代码仓库或发给他人**。
