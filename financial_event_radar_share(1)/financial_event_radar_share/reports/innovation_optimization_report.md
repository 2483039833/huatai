# 多维创新优化报告

本轮采用“实验可复现、指标优先、未达标不接入主链路”的原则，覆盖事件分类、方向判定、同源聚合和预警策略。

## 已接入：选择性预测与人工复核

个股事件分类的“第一名与第二名近邻分数差”可用作不确定性信号。对提供测试集的诊断结果：

| 最小分数差 | 自动判定覆盖率 | 自动判定准确率 |
| ---: | ---: | ---: |
| 0.03 | 84.55% | 83.90% |
| 0.05 | 77.75% | 86.70% |
| 0.10 | 64.66% | 93.72% |
| 0.15 | 61.52% | 95.53% |

系统采用“低于 0.03 进入人工复核”的保守规则。高优先级但分类不确定的事件不再直接推送，而会转入 `manual_review` 队列；本次预警结果中已有 3 条执行该动作。

## 事件定义检索：保留为冷启动兜底

| 方法 | 验证集 Macro-F1 | 提供测试集 Macro-F1 |
| --- | ---: | ---: |
| 同公司标题近邻（主模型） | 76.00% | 77.26% |
| 事件定义文本匹配 | 69.49% | 67.75% |
| 近邻不足时回退到定义检索 | 72.79% | 73.80% |

事件定义检索不适合作为当前主分类器，但新增公司缺少历史标注时仍可作为冷启动兜底，并能给用户展示“为什么归为该事件类型”的业务定义。

## 类别平衡方向判定：暂不替换稳定模型

方向标签高度不均衡。类别平衡的 IDF 类中心、关键词规则和投票模型在公司方向的 2 折验证中确实提高了少数类 Macro-F1，但会将总体 Accuracy 从 90.36% 降至 80.07%。鉴于当前监督字符模型在提供测试集上的方向 Accuracy 已达 95.42%，暂不替换主模型；后续可将平衡模型用于“负面/中性风险复核”的并行提示。

## 多特征去重学习器：拒绝接入

逻辑回归学习了标题/正文相似度、发布时间差、来源、标题一致性和正文长度等特征。在训练校准集达到 96.75% F1，但在提供测试集上 Precision 降至 49.50%、F1 降至 66.23%，出现明显分布过拟合。因此保留当前鲁棒的召回优先阈值策略：测试集 Precision 97.37%、Recall 85.79%、F1 91.21%。

## 当前主链路建议

1. 个股事件：同公司标题近邻 + 事件体系约束；
2. 行业事件：正文字符 n-gram + 事件体系约束；
3. 方向：监督字符 n-gram；
4. 去重：稀有字符召回 + 标题/正文相似度 + Precision 下限约束；
5. 低置信个股事件：人工复核后再进入高优先级推送。

下一步要取得更实质的泛化提升，需要接入句向量模型或大模型抽取，并使用与当前训练集独立的隐藏验证集进行模型选择。
