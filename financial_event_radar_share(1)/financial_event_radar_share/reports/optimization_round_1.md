# 第一轮指标优化报告

## 目标

在不引入外部模型或额外依赖的前提下，优先提高事件识别的 Macro-F1、影响方向准确率，以及同源新闻识别的对级 Recall 与 F1。

## 改动

1. 个股事件分类从“标题 + 正文”改为标题优先的字符 n-gram 分类器，降低长正文中的背景性信息对“技术突破 / 产品创新 / 战略调整”等相邻类型的干扰；行业事件仍使用正文混合模型。
2. 影响方向从关键词规则改为使用带标注训练新闻训练的监督字符 n-gram 分类器。
3. 去重阈值从最大化训练集 F1 改为“训练集 Precision 不低于 88% 前提下优先提高 Recall”，阈值由 0.73 调整为 0.45。

## 对比结果

| 模块 | 指标 | 优化前 | 优化后 | 变化 |
| --- | --- | ---: | ---: | ---: |
| 个股事件识别 | Accuracy | 78.66% | 81.15% | +2.49pp |
| 个股事件识别 | Macro-F1 | 67.98% | 73.52% | +5.54pp |
| 个股影响方向 | Accuracy | 66.10% | 95.42% | +29.32pp |
| 行业事件识别 | Accuracy | 97.52% | 97.52% | 0.00pp |
| 行业事件识别 | Macro-F1 | 96.82% | 96.82% | 0.00pp |
| 行业影响方向 | Accuracy | 54.96% | 85.82% | +30.86pp |
| 同源新闻识别 | Pair Precision | 99.53% | 97.37% | -2.16pp |
| 同源新闻识别 | Pair Recall | 67.16% | 85.79% | +18.63pp |
| 同源新闻识别 | Pair F1 | 80.20% | 91.21% | +11.01pp |
| 事件簇聚合 | B³ F1 | 95.90% | 97.94% | +2.04pp |

## 结论

- 个股事件识别与方向判定均实现明显提升；
- 去重模块以极小的查准率代价换取大幅查全率提升，更符合舆情预警“尽量不漏重大事件”的需求；
- 优化后重新生成了可信度、时间线、预警和仪表盘数据，确保全链路使用同一版结果。

## 评测边界

上述结果基于赛题提供的带标签测试文件。后续应从训练集划出独立验证集完成阈值和模型选择，再使用隐藏测试集进行最终汇报；这样可以避免围绕已见标签反复调参造成高估。
