# 同源事件聚合基线报告

方法：稀有字符 shingle 召回候选对，以标题和正文包含度计算相似度；在训练集保持至少 88% 对级 Precision 的前提下优先提高 Recall，再通过并查集生成事件簇。

- 选定相似度阈值：`0.45`
- 测试候选召回率：`100.00%`
- 测试对级 Precision / Recall / F1：`97.37%` / `85.79%` / `91.21%`
- 测试簇级 B³ Precision / Recall / F1：`97.35%` / `98.53%` / `97.94%`
- 输出事件簇：429 个，其中多文章簇 164 个。

后续将事件类型、主体、时间与可信度融入重排序模型，可降低同主体不同事项的误聚合，并提升改写报道的召回。
