# 金融事件雷达共享包说明

本共享包用于展示、复核代码和运行已有的看板/演示材料，不包含比赛提供的原始训练与测试新闻数据。

## 已包含

- 项目代码、README、运行脚本与答辩讲稿；
- 评测与优化报告；
- 已训练的本地语义模型检查点；
- 已生成的事件预测、聚合、可信度、时间线、预警和演示案例结果；
- 本地看板页面、答辩 PPT 与演示材料。

## 已排除

- 工作区根目录的原始 Excel 新闻文件；
- 工作区根目录的公司/行业事件体系原始 JSON；
- `data/processed/` 下的原始标准化训练、留出与无标签新闻；
- 临时缓存和 Python 字节码文件。

## 使用方式

1. 解压后进入项目根目录。
2. 已有结果可直接查看：运行 `python -m http.server 8080`，然后打开 `http://localhost:8080/web/`。
3. 如需重新训练或重建全流程，请自行取得比赛数据，并按主 README 的“数据准备”步骤放回对应位置后执行。

共享包内的模型和派生结果只用于项目演示与复核；未经原始比赛数据授权，不应将其替代原始数据集进行再分发。
